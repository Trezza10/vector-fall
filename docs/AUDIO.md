# Action audio

Run F5 and open Esc/Start > Settings > Sound. Master, Combat, Effects and UI sliders
preview immediately, with a mute switch and separate test buttons. Apply & save writes
controls and sound together to user://settings.cfg. Back/Esc/resume discards unsaved audio
previews. Saved values load on each launch; old control-only files keep sound defaults.
Graphics remains disabled WIP. Keyboard/controller focus and slider input use Godot UI controls.

All sounds are original mono PCM WAVs generated by tools/generate_audio.py. This basic
synthesized pass matches the technical interface style and can be replaced with richer
assets later. There is no music system yet.

| Actions | Bus / owner |
| --- | --- |
| Shot and auto-fire toggle | Combat / AutoShooter |
| Target hit, critical hit, kill | Combat / TargetDummy |
| Player damage and depletion | Combat / Player (shared hit/kill WAV cues) |
| Bullet wall impact | Combat / BulletImpact |
| Burn and poison damage ticks | Effects / TargetDummy |
| New ice, stun, knockback, mark and other status application | Effects / TargetDummy |
| Pickup collection and recharge | Effects / UpgradePickup |
| Dash, soft movement pulses, wall contact, reset | Effects / Player |
| Target respawn | Effects / TargetDummy |
| Pause, resume, settings buttons and tabs | UI / PauseMenu |

Players are fixed scene children; runtime code only triggers them. ActionSound exposes
Minimum Interval and Pitch Variation. Each player's stream, bus, volume and max polyphony
are editable in its owning scene. Per-owner cooldowns and three-voice caps reduce repeated
noise. Shot/hit cues use conservative levels, movement is especially soft, and the Master
bus has a -1 dB hard limiter for busy mixes. Cues use non-positional playback in this first
pass. Gameplay voices and cooldowns freeze on pause; menu previews remain active.

Verification: audio_check covers action triggers, pitch/retrigger bounds, pause, sound-tab
availability, live bus values, zero-volume mute, saved values, controls preservation and
cancel rollback. Existing combat, status, pickup, dash and pause checks verify the hooks do
not change gameplay. Sound settings were rendered and inspected. PCM assets are checked
for duration, nonzero output and clipping; audible balance remains a playtest tuning choice.
